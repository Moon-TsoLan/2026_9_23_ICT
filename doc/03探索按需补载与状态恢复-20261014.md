## 底图和当前问题

默认底图沿用采购单位/项目全量、高频供应商采样。一次会话中底图数组、布局尺度、雾线采样与骨架固定；搜索与场景结果进入临时集合，不再追加到默认底图。

`projectGraph`按节点ID、关系端点与角色合成当前展示集合，剔除缺失端点；已选主体有独立持有关系。退出问题清除临时集合，回到同一会话的底图。图例过滤保持用户设置，焦点和对比篮主体受可见性保护。

`StarMap`仅在底图或布局模式改变时全量重建；普通补载按ID创建/删除星体，复用已有星体、拾取体和标签DOM。新增关系只用于落位或当前问题的曲线层，不重建雾线/骨架，不重新计算雾密度和星尘范围，也不自动重新取景。雾线原有六组天区呼吸和强调态亮度保持。

## 查询、分页与来源

`GET /api/graph/neighborhood/{party_id}`独立于采样，支持采购单位、项目、投标供应商、产品供应商和品牌替代主体。

- 输入：原主体ID、expected_version、offset及limit（默认30、上限100）。
- 输出：权威主体节点、graph、data_version、pagination（offset/limit/total/has_more）。
- 供应商关系包括投标/中标及明确产品供应；企业通过既有norm_name规范查询复用sup身份，品牌保留brand身份。
- 项目详情直接查询该包的投标人与产品供应方；按主体分页，同一主体的多种角色一并返回，不把底图采样名单当作完整名单。
- 版本检查在查询前后进行；不同版本拒绝整个补载，返回409。总览与场景接口同样携带/校验版本。
- 搜索补齐产品供应商与品牌替代入口；不更改既有S3/S4/S5中标供应商资格。

前端分别记录节点存在与关系页覆盖。仅在选中/项目详情/挑选态展示加载数量和“加载更多关系”；场景查询的答案数量不混用补载页覆盖。S6列表统计已加载部分，分页提示始终显示完整关联对象总数。

## 状态和请求一致性

搜索、点选、外部目标与加入对比篮都使用相同补载入口。顺序为主体确认、临时数据合入、渲染就绪、提交选中/篮中成员、定位镜头。失败保留原问题，不宣称加入成功。

操作代次与AbortController共同取消旧请求；新搜索、退出、移除成员或离页之后，旧回答不能覆盖当前状态。档案查询有独立代次，搜索候选也阻止旧回答覆盖。加入对比篮在异步完成时再次校验中标资格、重复ID与4家上限。

对比篮存ID与名称，不从中文标签反查ID；所有已选主体持续保留，空交集也保留主体节点。挑选态/对比态均有主体颜色环和优先标签，名称可从篮中逐个定位。“查看全部已选”按视野角和画布宽高比取景，不再用整图距离上限裁切。相机动画按实际经过时间完成；已选主体标签不等待普通标签的滞回。

场景结果锁定时搜索/图上换主体需要先退出。面板明确增删成员会清除结果并返回挑选态。空交集不回退绘制历史邻域。

## 换页面和重建

| 操作 | 行为 |
|---|---|
| 首次进入 | 建立默认底图会话 |
| 去检索/档案后普通返回 | 恢复底图、临时数据、模式、篮、问题、图例与镜头，不重新采样 |
| 档案页明确“在星图中查看” | 新导航意图优先，选中目标并结束旧问题/篮；沿用会话底图 |
| 相同03页面改变focus参数 | 监听新目标并走统一入口 |
| 整页刷新 | 内存会话失效；无目标URL回默认，有focus的深链初始化并定位其目标 |
| 回到全景/Esc | 清除问题与临时展示，保留底图和图例设置 |
| 数据更新 | 提示，不自动混入新版本；用户刷新后建立新底图会话 |

会话快照仅在当前应用内存保存，不写localStorage；记录可序列化业务数据、节点坐标、镜头/OrbitControls范围、雾呼吸时间及透明度。离页释放WebGL、事件、帧循环和轮询；切回仍需创建一次渲染资源。布局坐标在挂载时按会话恢复，避免旧模块缓存与新页面状态脱节。档案深链有独立导航意图标识，区分普通返回和明确换目标。
