# 赛题五基准集数据分析

统计日期：2026-09-23。对象是 `data/赛题五基准测试数据` 的全部公告，不是 `data/fake20`。

抽取结构与流程以 `docs/ICT结构、语义与项目流程规定.md` 为准。本文只保留当时数过的结果，供新会话直接使用。明细 JSON 在 `run/official_pinmu_eda/`（gitignore，不入库）。

判定口径：

- 公告概要「品目」按单元格原文。空字符串算空。多条路径按逗号或编码拆开。
- 主要标的只看结果表（品目、采购标的、品牌、规格、服务范围、施工范围），不含供应商得分表。
- 单元格在去掉「招标文件 / 磋商文件 / 采购文件 / 投标文件 / 附件 / 详见」等字样后，还留下至少 8 个字，才算实值。否则算指向文件。`1(套)`、空、`无` 另计。
- 万元换算、包级合并规则不在这次统计里，那些已写进结构约定。

## 5. 和现行约定的对应关系

这些数支持 `docs/ICT结构、语义与项目流程规定.md` 里已经写定的做法：

- 项目键用项目名称 + 包编号，不把同一采购编号下的不同包合成一个项目。
- 概要总金额是这一篇里各包的合计。单包可直接当作包金额；多包不用这个合计填每一个包。
- 品目按行取「品目名称」一类的列，对到目录的哪一级就写哪一级。「品目号」不写入品目。
- 货物行的品牌、规格、数量、单价在列存在时多数是实值。服务行要补的主要是服务要求、服务标准、服务范围。
- 附件先绑公告再绑包。成员以 PDF 和嵌套 zip 为主。
