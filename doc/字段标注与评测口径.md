# 字段标注与评测口径

2026-11-08。按用户最新明确约定执行，旧10-10口径见[历史快照](archive/字段标注与评测口径-20261013前.md)。不能根据系统自己记录的计算或推断来源自行免评。

## 投标人字段政策

候选仍按原文明示报价、供应商成交金额与审查结论分别抽取。最终明确报价优先；中标人未披露单独报价时采用其明确归属的供应商成交金额；未明确失败的已确认投标响应主体默认通过。已存在的未决冲突不以政策覆盖。抽取、最终组装、详情与导出共用此政策，不以政策来源自行免评。

历史成品仅政策回放必须单列，不能计为新模型准确率；模型/流程实验在相同政策下比较。冻结金标和原始文件不因政策更新而改写；与新政策冲突的标注格须单列人工核对，不按开发样本调词或自动改标。

## 逐格政策

| 金标格 | 系统输出 | 是否正确 |
|---|---|---|
| 普通格为空 | 空 | 正确 |
| 普通格为空 | 有值 | 错误，多抽 |
| 普通格有值 | 与金标一致 | 正确 |
| 普通格有值 | 空或错误值 | 错误 |
| 填色推理格 | 与金标一致或空 | 正确 |
| 填色推理格 | 其它有值 | 错误 |

填色是数据格的人工标记；蓝灰表头颜色不是推理格。白色填充不当作推理格。此前14份CSV伪装xlsx不保留底色，用户已确认没有推理格，按现有值比较。
官方灰色字段不是必需评分字段；新增单位、产品供应商、品目编码和ABC可单独统计，不混入蓝色字段主成绩。

## 新三表关联与金额

UUID按公告唯一标识原样保留，含下划线，不添加包后缀。三表用同一标段/合同包原文名称关联；总表一中标人一行，标的表一标的一行，投标人表一供应商一行。
重复名称对象保持一对一匹配，不能把多条价格或数量不同的采购明细自动合成一条。未匹配对象分别计漏抽、多抽，不制造不存在的空白负例行。
新版金额均按导出边界转换为万元两位后比较。不能对万元字段沿用旧评分器0.01元的容差，也不能用舍入后单价乘数量验证总价。数量为数值，单位另列。
`ict.official.read_gold_workbook`读取三表字段及数据格底色，跳过说明/示例标记行；`score_gold_cell`实现上述逐格政策。

## 指标解释

- 字段准确率：金标范围内正确格数/金标计分格数；一个错误值在这个分母中只算一个错误。
- 精确率：正确有值格/(正确有值格+错误有值格+普通空金标的多填格)。另报计入多抽对象所有有值字段后的精确率。
- 召回率：正确有值格/(正确有值格+错误有值格+普通有值金标的漏填格)。填色格允许空，接受空输出不算漏填，也不算提取到一个正确值。
- 金标普通空、输出空可计正确空格；填色格允许的空单列，不能把它冒充正确提取值。
- 实体精确率/召回率单独报告；多抽对象不能通过补大量假空格加入字段准确率分母。

错误有值可能同时贡献FP和FN，因此TP+TN+FP+FN不一定等于金标格数。格准确率和有值精确率/召回率应分别按上述定义计算。
旧50例成绩保留历史版本与原单位口径。11月8～9日用户已授权真实API及针对性修复；当前分层验证见[报告](../eval/公告前半程修复与分层验证-20261109.md)。冻结源工作簿与快照有效行数为98/437/308，未改金标；填色政策单列，未匹配实体不制造空行免评。

仅公告试验不使用附件独有值作为公告召回分母。当前字面名称子集319/332、301/306只作窄诊断，不代表全字段准确率；完整案例三表对照另列，人工可得性与页标签未确认时不宣称质量通过。实现与API版本的固定回答等价回放不算新的准确率试验。
