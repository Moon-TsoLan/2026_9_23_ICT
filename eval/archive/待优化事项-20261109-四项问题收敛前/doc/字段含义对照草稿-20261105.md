# 字段定义对照稿（不接入运行）

本稿用于比对，不修改 `src/ict/fields.py`、提示词、规则或模型调用。覆盖当前实际调用的 13 个提示词版本所登记的全部字段；不覆盖未被这些版本使用的历史字段。

## 阅读说明

- “建议定义”只描述含义、表示或取值；步骤如何判断、选取、校验和处置，保留给各步骤任务指引。
- 标记“已拟稿”的条目均为供审阅的候选文字，尚未决定用于生产，也尚未逐条验证与全部代码和提示词等价。
- 同一字段如果在不同步骤承担不同含义，必须在步骤专属定义中说明；本稿把现有专属定义列在文末，供逐条比对。
- 本稿不改变字段含义、取值、规则或处理流程；候选文字如果看起来可能改变现行判断，以现行实现为准并标记待裁定。

## 怎么读这 197 个字段

197 是当前 13 个提示词版本的字段登记表 `STEP_FIELDS` 中，输入和输出名称去重后的数量；它既包含业务值，也包含原文、上下文、来源引用、状态、审计和模型操作。**不是最终三表或最终业务结果的字段数**，也不是所有条目都会出现在每次请求中。同名字段跨步骤只计一次，不同名的同义或近义字段分别计数。

字段表中的“步骤及方向”依据各版本在 `STEP_FIELDS` 中的登记生成：**入**表示登记为输入字段含义，**出**表示登记为输出字段含义。登记用于生成模型可见的字段解释，不保证该字段每次都在实际 JSON 顶层出现，也不证明一定被代码读取；嵌套字段、可选字段和历史残留都可能在内。原生抽取复用“6附件抽取”的提示词，包归属可在 HTML、原生和附件观测后再次调用。第 3、7 步没有独立提示词，因此不在这张提示词登记表的使用步骤内，不能据此判断其实际不使用该字段。

“最终结构同名”仅与 `Cob`、`Sub`、`Project` 模型及公告外壳字段名比较，显示“是”不保证每条结果有值或对应官方导出列；显示“否”也不代表字段无用或可以删除。公告、包、标的、供应商分别是不同层级，不应把同名出现次数简单相加。

## 需要先裁定的语义

1. **quantity**：现行字段文字笼统排除人数、面积、点位数；计价单位却包含“人”。建议定义只说明“当前计量口径”，是否改变该绝对排除要求须单独裁定，当前代码和提示词不变。
2. **raw_text 与表头单位**：现行附件提示词要求拼接本列表头单位，字段解释又要求照抄。需要决定是保留拼接格式并明确它是来源组合文本，还是另设原单元格与单位承载；本稿不预先决定。
3. **package_no**：第 1 步的原文编号与后续内部引用同名但不同义；草稿明确两种用途，不改变数据结构。
4. **总价**：抽取值、计算值和包金额引用的处理条件属于步骤指引；字段本身描述业务含义。第 7 步计算行为仍按现行实现，不因本稿改变。
5. **未知中标状态**：本稿字段含义不改变现行缺失转 False 的行为；是否区分未知与否需另行决策。
